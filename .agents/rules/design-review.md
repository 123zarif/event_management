# ClubSphere Design Review

Before implementing a major page or redesign, inspect the existing UI and identify:

- Existing spacing patterns
- Typography hierarchy
- Component reuse opportunities
- Existing navigation
- Existing button hierarchy
- Existing surface/border treatment
- Responsive behavior

Do not invent a new design language for one page.

Before finishing the implementation, critically inspect the result for:

- Excessive cards
- Excessive rounded corners
- Excessive badges
- Excessive icons
- Excessive gradients
- Excessive blur
- Excessive shadows
- Excessive animation
- Oversized typography
- Generic AI-dashboard composition
- Poor information hierarchy

When two designs communicate the same information, prefer the more restrained and information-efficient design.

Reuse established project patterns unless there is a clear usability reason not to.
